Conditional aggregation allows you to compute several answers in one pass over the data. If you were to use two queries, it would go over all the data twice to answer the questions that the two queries would be asking. Now for our case for a couple of hundred rows of data, the difference isn't that big and doesn't cost much in terms of performance. Now imagine if you were to run this on a table with millions of records. That could cause some serious performance issues with the query. It would be half the work to run the query with a conditional aggregation because it runs through that data only once. Overall, it would be better on a table with a lot of data to do a conditional aggregation over two queries due to cost, but it is also easy to add more metrics it would just be another case column.
